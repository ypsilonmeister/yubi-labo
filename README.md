# さんすうクラフト（yubi-labo）

数の合成・分解・位取りを、数式ではなく「形の操作」として扱う算数学習Webアプリです。
小学2年生の息子ひとりのために設計し、家族のフィードバックで育て続けています。

## これはなに

「構造は見えているのに、入口の形式で止まる」子どものための、ブラウザ完結型の算数アプリです。

- 問題として数式を出さない。式と答えは、本人が「かずで みる」を押したときと、試行が終わってからだけ表示する
- すべてのデータは端末内（IndexedDB）にのみ保存され、外部送信はしない
- 1問ごとに次を決めるのは本人で、自動では進まない

設計の正本は [docs/SPEC.md](docs/SPEC.md)（現在 v2.14）です。本READMEは概要のみを扱い、仕様の詳細はSPECを参照してください。

## こだわった3点

1. **数式を出さない、急がせない** ― タイマーやカウントダウンは置かず、速さを点数にも評価にも使わない。「がんばれ」「あと少し」「早く」の文言も使わない
2. **間違いを罰しない、楽しさを煽らない** ― 赤い×、ブザー、「ざんねん」は使わない。誤りは「形が合わない（あふれる／隙間ができる）」として示す。点数は付けても減点はせず、コンボ・倍率・日ごとのノルマも設けない
3. **外に出さない、勝手に進ませない** ― 全データは端末内に保存。目標の枠と比較の対象は操作中ずっと画面に残し、「見せてから隠して覚えさせる」課題は作らない。音は初期OFFで、無音でも全課題が完結する

## モード一覧（A〜L）

| | モード | 子ども向け表示名 | 内容 |
|---|---|---|---|
| A | 偶奇パズル | かたちパズル | 数を2列プレートの形と対称性で扱う |
| B | カラーロッド | いろぼう | 長さと比率で扱う |
| C | 10フレーム | 10の へや | 繰り上がり・繰り下がりを「容量10の器が満ちる／あふれる」現象として扱う。2桁にも対応 |
| D | 両替商 | りょうがえや | お金の両替という交換システムの拡張として位取りを扱う。2桁（加数法）にも対応 |
| E | タイル | タイル・リアクター | タイルで数を作る（じっけんラボ） |
| F | シーソー | シーソー | 釣り合いを観察する（じっけんラボ） |
| G | 倍と半分 | ばいばいラボ | 倍・半分の課題（じっけんラボ） |
| H | 列車 | ぼうの れっしゃ | 周期を観察する（じっけんラボ） |
| I | はんぶんチャレンジ | はんぶん チャレンジ | 4桁の数の半分を選び、半分・また半分と連鎖させる。本人の希望で生まれたモード |
| J | ジオボード | ジオボード | 5×5の点をタップして輪ゴムを伸ばし、形を作る自由探索。線を引かず、定規も使わない |
| K | かたちづくり | かたちづくり | ジオボードの課題版。最初の1辺から目標の形（正方形・二等辺三角形・広さなど）を作る |
| L | タイルの かけわり | タイルの かけわり | タイルの配列で掛け算・割り算。あまりのある割り算や、2桁×1桁を「10の列と残り」に分ける橋渡しを含む |

このほか、作ったものを残す **クラフト図鑑**（表示名：つくった もの）があります。

## 開発

```bash
npm install
npm run dev     # 開発サーバー
npm test        # テスト（Vitest、148件）
npm run build   # 本番ビルド
```

- 技術構成: React / TypeScript / Vite。データ保存は IndexedDB のみ
- モードはプラグイン型で追加・差し替えが可能。繰り上がり・繰り下がりの全組合せなどをテストで幾何学的に検証している
- PRごとに `npm test` と `npm run build` を回すCIが入っている
- 本番は GitHub Pages にデプロイされている
